## 🌟 Overview

**Editor PDF Pro** is a modern document editing application that operates 100% on the client side. By leveraging WebAssembly and modern canvas rendering, users can manipulate confidential documents locally without ever uploading sensitive PDFs to third-party servers.

---

## ✨ Features

- **Page Operations**: Reorder, rotate, extract, split, and merge multi-page PDF documents.
- **Rich Annotations & Drawing**: Freehand pencil, highlight, text insertion, stamps, and geometric shapes.
- **Digital Signatures**: Draw, import, or generate digital signatures with transparent background overlays.
- **Privacy & Security First**: All processing runs locally inside the browser Web Worker/WASM sandbox.
- **Export & Compression**: High-fidelity PDF rendering with optimized rasterization and vector preservation.
